C2PA Image Proof Schema v1

Canonical schema URL: https://anchr-spec.org/spec/proof/c2pa-image/v1

This schema identifies an image proof whose C2PA Content Credentials manifest is cryptographically verified and whose signed GPS assertion is bound to the request's expected location.

Predicate Shape

The predicate describes the expected capture location and accepted distance window for the signed GPS assertion. 

{
  "expected_gps": { "lat": 35.6762, "lon": 139.6503 },
  "max_distance_km": 1,
  "accepted_mime_types": ["image/jpeg", "image/png", "image/webp"]
}
Field Meaning
expected_gps Latitude and longitude the signed C2PA GPS assertion must match.
max_distance_km Maximum accepted distance between signed GPS and expected GPS.
accepted_mime_types Optional image media types accepted by the verifier.

Proof Payload Shape

The proof payload contains the image bytes or an encrypted attachment reference to the exact image bytes. The image must carry a C2PA manifest with an EXIF GPS assertion. 

{
  "image": "<bytes or attachment reference>",
  "filename": "capture.jpg",
  "mime_type": "image/jpeg"
}

Response Data Shape

On success, verifiers expose the verified manifest summary and signed coordinates used for the verdict. 

{
  "claim_generator": "camera-or-app-name",
  "signature_issuer": "certificate issuer",
  "signed_at": "2026-06-11T00:00:00Z",
  "gps": { "lat": 35.6762, "lon": 139.6503 },
  "distance_km": 0.0
}

Verification Requirements

  • Reject payloads without a C2PA active manifest.
  • Verify the C2PA manifest signature cryptographically.
  • Reject manifests with claim-signature or assertion data-hash failures.
  • Extract GPS only from an EXIF assertion covered by the verified manifest.
  • Reject payloads whose verified manifest does not contain signed GPS.
  • Reject payloads whose signed GPS is farther than max_distance_km from expected_gps.
  • Reject unsupported or non-image payload types.
