@anchr/sdk

An SDK for verifiable paid requests

A Customer publishes a payment budget, selects one Provider, and locks payment for that Provider’s requested amount. The Provider returns work with proof and can redeem only after a trusted Oracle accepts the proof, removing the pay-first / deliver-first deadlock for off-chain work.

ACTOR API

Provider

The Provider offers to complete a Paid Request for a Requested Payment Amount, returns Work with Proof, and redeems payment after valid release. serve() runs a handler for every incoming request; return null to decline.

{{ providerServeCode }}
!

Verify before irreversible work. A Provider must verify the selected Payment Lock before doing the Work, and keep redeem decisions narrower than clean-settlement or audit decisions. The normative rules live in specs/paid-request-exchange.md.

ACTOR API

Oracle & proofs

The Oracle verifies Proof and produces Release Material for valid Work. It never holds funds; it only controls whether the Cashu HTLC unlock secret is released. Each request carries a schema URL that the Provider’s handler interprets.
